# 볼링 전국대회 페스타 — 리디자인 가이드

이 문서는 Cowork에서 만든 디자인 시안(Design 아티팩트, 화면 8개)을 실제 `naverbowlfesta` 코드베이스에 적용할 때 참고할 스펙입니다. Claude Code 세션에 이 파일을 붙여넣거나 리포지토리에 함께 두고 "이 가이드대로 디자인을 적용해줘"라고 요청하면 됩니다.

실제 사이트 확인 결과 프레임워크(React 등) 없이 순수 HTML/CSS + 여러 JS 파일(`app.js`, `store.js`, `ranking.js`, `lanes.js`, `signup.js`, `xlsx.full.min.js` 등)로 구성되어 있습니다. 아래 값들을 전역 CSS(변수 또는 기존 스타일시트)에 반영하고, 각 탭의 마크업 구조를 화면별 스펙에 맞게 조정하면 됩니다. DOM은 JS가 데이터로 렌더링하는 구조이므로, 시안의 HTML을 통째로 복사하기보다 **아래 토큰과 레이아웃 구조를 기존 렌더링 로직에 적용**하는 방식을 권장합니다.

## 1. 디자인 토큰

### 컬러

| 용도 | 값 |
|---|---|
| 배경(페이퍼) | `#F5F2EA` |
| 카드 배경 | `#FFFFFF` |
| 테두리(헤어라인) | `#E6E1D3` / 연한 구분선 `#F0EDE3` |
| 본문 텍스트 | `#1B1B1F` |
| 보조 텍스트 | `#6B6B72` / 옅은 텍스트 `#9C9C9C` |
| 헤더·사이드바 네이비 | `#1E2537` (더 옅은 패널 `#2B3348`) |
| 네이비 위 보조텍스트 | `#AEB3C2` / 비활성 `#7C8093` |
| 포인트 오렌지(강조) | `#FF5A2E` |
| 오렌지 진한 텍스트용 | `#C23F17` |
| 오렌지 연한 배경(칩/뱃지) | `#FFE3D6` / 입력칸 강조 배경 `#FFF6F2`, 테두리 `#FFCDB8` |
| 진행중 상태(초록) | 텍스트 `#2F8F5B`, 배경 `#E1F3E9` |
| 순위 메달 | 금 `#D8A93B` / 은 `#9AA0A6` / 동 `#B57A4D` |

### 타이포그래피

```html
<link href="https://fonts.googleapis.com/css2?family=Black+Han+Sans&family=Noto+Sans+KR:wght@400;500;700;900&display=swap" rel="stylesheet">
```

- 제목/큰 점수/랭크 숫자: **Black Han Sans** (굵고 임팩트 있는 스코어보드 느낌)
- 본문/표/라벨: **Noto Sans KR** (400/500/700/900 사용)

### 형태

- 카드 radius: 16~20px
- 버튼/칩: pill(999px) 또는 9~11px
- 카드 테두리: 1px solid `#E6E1D3` (그림자 없이 얇은 테두리로 구분 — 좌측 컬러바 스타일은 지양)
- 터치 타깃 44px 이상

## 2. 회원용 모바일 (390px 기준, 하단 탭 내비게이션)

공통: 상단은 네이비(`#1E2537`) 헤더, 하단은 4개 탭 고정 바(홈 / 검색 / 배정 / 순위), 흰 배경에 테두리 카드로 콘텐츠 구성.

**중요:** 회원별 개별 로그인이 없으므로 "내 정보(로그인 기반)" 화면은 만들지 않았습니다. 대신 모든 개인화 화면은 **이름 검색 기반**으로 동작합니다 (검색창에 이름을 입력하면 해당 선수의 정보/레인/순위를 보여주는 방식).

1. **홈** — 대회명(Black Han Sans), 주최 동호회, 진행 상태 뱃지, 진행률 바. 아래 퀵메뉴 3개: 선수 검색 / 레인 배정 확인 / 실시간 순위. 대회 안내(일정·규정 요약) 카드.
2. **선수 검색** — 상단 검색창(이름 입력) → 검색된 선수의 참가 종목(개인전/스카치/베이커 체크 상태), 핸디·총점가감 정보 표시.
3. **레인 배정** — 조 선택 칩 + 이름 검색창 → 검색 결과 카드(큰 레인 번호, 순번, 조, 시작시간) + 해당 조 전체 명단 표(검색된 선수 행 강조).
4. **순위** — 개인전/스카치/베이커/지역종합 탭, 남녀·조 필터, 이름 검색창 → 상위 3명 포디움 카드 + 이하 순위 리스트(검색된 선수 강조).

## 3. 관리자용 PC (1440px 기준, 좌측 사이드바)

공통: 좌측 240px 네이비 사이드바(로고 + 8개 메뉴: 홈/선수/배정/개인전/스카치/베이커/지역종합/설정, 활성 항목은 오렌지 배경), 상단바(페이지 제목 + 대회 상태 뱃지 + 관리자 계정), 본문은 페이퍼 배경에 흰 카드.

1. **대시보드** — 참가 선수/레인/진행률/확정 결과 통계 카드 4개, 결과 관리 카드(대회 시작·최종 확정 버튼), 빠른 실행 카드(선수 등록/레인 배정/점수 입력으로 이동).
2. **선수 관리** — 지역 관리 미니폼, 선수 등록 폼(이름/지역/성별/생년/핸디/조/출전종목 체크박스), 참가자 테이블(필터+CSV/인쇄), 엑셀 업로드 + 텍스트 일괄 등록 카드.
3. **조 편성·레인 배정** — 조 선택 탭, 인원 현황 + 자동 편성 버튼, 시작레인/레인당인원 입력 + 자동 배정 버튼, 편집 가능한 배정 테이블(드래그 핸들 표시).
4. **점수 입력·집계** — 성별/조 필터 + 점수입력 탭, 자동저장 상태 뱃지, 레인별 점수 입력 테이블(G1/G2/G3는 입력칸 스타일, 합계/총점은 계산값 스타일로 구분), 하단에 실시간 집계 미니 순위표.

## 5. Claude Code에 붙여넣을 때 사용할 수 있는 프롬프트 예시

```
아래 design-guide.md 내용대로 이 리포의 디자인을 적용해줘.
- index.html / 스타일시트에 1번 섹션의 색상·폰트 토큰을 전역으로 반영
- app.js / store.js / ranking.js / lanes.js / signup.js가 렌더링하는 각 탭 마크업을
  2번(회원용 모바일)·3번(관리자 PC) 섹션의 레이아웃 구조에 맞게 수정
- 회원 화면은 로그인 없이 "이름 검색"으로 개인 정보를 조회하는 방식 유지
- 기존 데이터 바인딩/로직은 그대로 두고 마크업·스타일만 교체
```
